# 製品の動き（短い正本）

検索結果は Twitter で見る。このアプリは検索 URL とツイート作成 URL を組み立てるだけ。

- 投稿検索と人検索をワンクリックで開く。
- キーワードは OR 結合し、引用符で囲める。自分の投稿は `-from:` で除外。自分の過去投稿は `from:`。
- 最新（`f=live`）、メディア（`filter:media`）、日付、共有 URL。
- 初期画面は空。訪問者のユーザー名・キーワード・プリセットは `localStorage` に残す。
- ぬぬはらは作者の個人サンプルであり、初期値ではない。
- 検索 API・スクレイピング・ログイン・有料 API は使わない。静的エクスポートのみ。

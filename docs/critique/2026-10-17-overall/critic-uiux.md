# 批評: 使いやすさ・UI/UX（2026-10-17）

立場: スマホ（390×844・タッチ）と PC（1280×800・1920×1080、マウスとキーボード）で初めて触る人・毎日使う人、画面を作る人。
見た方法: 開発サーバー http://127.0.0.1:43141 をヘッドレス Edge（CDP、ポート 9352）で操作。スクショは `uiux/`（sp-* がスマホ、pc-* が PC）。送信・X への遷移・書き込みはしていない。YouTube API は 1 回読み込んだだけ（@nnhr_nunu、271 本、約 4 秒）。
既知の指摘は「既知 Q-xxx」と書く。画面左下の「N」は Next.js の開発用の印で、本番には出ない。

## 1. 点

**総合 4 / 5** — 毎日の「開いて 1 回押す」はすでに短い。足りないのは、スマホで毎日押す所の小ささと、色の役割の混ざりと、「押すと何を探すか」がボタンのそばに無いこと。どれも直す場所がはっきりしていて、小〜中の手間。

| 観点 | 点 | 一行の理由 |
|---|---|---|
| スマホの主な流れ | 3 | 2 回目からは 1 タップで済むが、毎日押す設定タブが 25px、チップの × が 18px で、× は押すとすぐ消えて元に戻せない（既知 Q-004） |
| PC の主な流れ | 4 | 開くと名前欄にカーソルがあり、打って Enter で足せる。検索はマウスで 1 回。キーボードだけだと Shift+Tab 4 回で戻る |
| 分かりやすさ | 4 | 見出し・ボタンの言葉は短くて分かる。ただ、X の検索にはログインが要るのに「ログイン不要」と大きく書いてある（既知 Q-016。市場調査 3-1 で、X の検索はログインが要ると確認できた） |
| 一貫性 | 3 | 選んでいる切り替え（最新順・期間・種類）が「投稿を検索」と同じ濃い青の塗りになっている。選んでいる物の見せ方も 2 通り（設定タブは白い札、切り替えは青い塗り） |
| 崩れ・状態の表示 | 4 | 320・360・390px で横にはみ出さない。下の固定ボタンは、打っている間と広告が見えている間は隠れる。足りないのは、フォーカスの枠が薄いこと（既知 Q-052）と、大きいチャンネルを読み込むときの待ちの表示（既知 Q-012） |

## 2. 主な流れ（場面ごと）

### スマホ（390×844、初めて → 翌日）

1. **開く**（`uiux/sp-01-first.png`）: ヘッダーが上から 169px を取る。その下の y=197 に「設定1・設定2・設定3・YouTube」のタブがあり、どれも 88×25px。y=258 に「投稿を検索」があるが、まだ押せない薄い青で、下に「下の欄に名前かアカウントを入れると検索できます。」と出る。**この画面で一番目立つのは、濃い青に塗られた「最新順」**で、押せないボタンより強く見える。名前欄は y=538 にあり、最初の画面に入っている。
2. **名前を入れる**（`sp-03-added.png`）: 欄を押して「ぬぬはら」と打ち、Enter でチップになる。カーソルは欄に残るので、続けて打てる。「表記ゆれ候補 ＋ヌヌハラ ＋ﾇﾇﾊﾗ」が出るが、高さ 22px。チップの × は 18px。
3. **条件を足す**（`sp-04-scrolled.png`、`sp-23-range.png`）: 絞り込む・期間・除外するが 1 列に並び、ページは約 2,570px。下まで行くと検索ボタンは画面の外になるが、欄から指を離すと画面の下に固定の「投稿を検索」が出る（`sp-11-floating.png`）。打っている間は出ないので、キーボードの上を塞がない。よくできている。
4. **押す**: X が新しいタブで開く。X の検索はログインしないと開けないので（市場調査 3-1）、X にログインしていない人はここで初めてログイン画面に止められる。上の「ログイン不要・無料。」を読んだ人には裏切りになる（既知 Q-016）。
5. **戻る**: 0 件でも、新着がなくても、ツールの画面は何も言わない（既知 Q-015・Q-021）。
6. **翌日**（`sp-10-revisit.png`）: 開くと、タブの名前が「ぬぬはら」になっていて、y=258 の「投稿を検索」を押すだけ（**1 タップ**）。別の設定を使う日は 25px のタブを押してから押す（2 タップ）。片手の親指では、上から 30% の位置は届きにくい（既知 Q-013）。
7. **共有**（`sp-13-share.png`）: シェアの画面は 725px で、844px の画面に収まる。「X でポスト」が塗り、「リンクをコピー」が枠、「ほかのアプリ」が文字だけで、役割の順に強弱が付いている。閉じる × は 28px、文面の型の切り替えは 76×28px と小さい。
8. **YouTube タブ**（`sp-15-youtube.png`、`sp-31-yt-loaded-full.png`）: URL を貼って「読み込む」を押すと、チャンネルのカードが出る。「2026/10/10 以降に公開された動画 1 本のリンクを貼った投稿を探します。」という要約は y≈975 にあって、最初の画面に入らない。一番上の「X で反応を検索」を押すとき、何を探すのかが目に入らない。

### PC（1280×800、1920×1080）

1. **開く**（`pc-01-first.png`）: 中身は幅 624px で真ん中に置かれる。**名前欄に初めからカーソルがある**ので、すぐ打てる。1920px でも同じ幅で（`pc-27-1920.png`）、左右は空く。広告の縦長の枠（160×600）は、ID が入っていない開発環境では出ない。入力の 1 列なら幅 624px で読みやすく、間延びは感じない。
2. **打って Enter → チップ → 検索**: マウスなら上の「投稿を検索」を 1 回押すだけ（y=242、最初の画面に入る）。キーボードだけで使う人は、Enter がチップを足す操作なので検索を開けず、Shift+Tab を 4 回押して戻る必要がある。決まったキー（Ctrl+Enter など）は無い。
3. **Tab で順に進む**: 設定タブ → 投稿を検索 → 並び順（1 回で止まる）→ シェア → 引き継ぎ → 名前欄 → 追加 → 各 × → 候補 → … の順で自然。ただ、チップの × に来たときの枠はほとんど見えない（`pc-22-focus-7.png`、既知 Q-052）。
4. **下のほう**: ページは 2,350px。下まで行くと固定の検索ボタンが出る（マウスの画面では、打っている間も出たまま）。
5. **引き継ぎ**（`pc-14-transfer.png`）: 「引き継ぎ用リンクをコピー」が塗り、「ほかのアプリへ送る」が文字だけ。分かりやすい。ただ、入口は 12px の注記の中の小さなリンク（108×24px、既知 Q-023）。

## 3. つまずく所の上位 3（直し方とファイル:行）

1. **スマホで毎日押す所が小さく、× で即座に消える**（既知 Q-004。一番の優先）
   - 実測: 設定タブ 88×25px（`src/components/ui/tabs.tsx:65` の `h-[calc(100%-1px)]` と `py-0.5`、外枠の高さ 32px）、チップの × 18px（`src/components/chip-input.tsx:142` の `size-3.5`）、表記ゆれ候補 22px、シェアの型 76×28px、閉じる 28px。
   - 直し方: 設定タブは `slot-tabs.tsx` 側で高さを 40〜44px に上げる。× は見た目をそのままにして、押せる範囲を `after:` の疑似要素で 44px に広げる。消したら「元に戻す」を数秒出す。候補チップは 32px 以上にする。

2. **選んでいる切り替えが「してほしいこと」と同じ濃い塗り**（新しい指摘。design-tips の 5 に反する）
   - `src/components/segmented.tsx:10` の `selected ? "bg-primary text-primary-foreground"`。最新順・期間・種類・YouTube の期間は、どれも「投稿を検索」と同じ #1da1f2 の塗りになる。最初の画面では、押せないボタンが薄い青なので、「最新順」が一番強く見える（`sp-01-first.png`）。PC で見ても、塗りの帯が 3 本（検索・最新順・期間）並ぶ（`pc-27-1920.png`）。
   - 直し方: 選んでいる切り替えは、設定タブと同じ「白い札に濃い文字＋影」にするか、薄い青の地に青い文字（`bg-primary/10 text-primary`、枠を付ける）にする。濃い塗りは「投稿を検索」「X で反応を検索」「X でポスト」だけにする。Q-002（主色のコントラスト）と一緒に直すと、見た目の変更が 1 回で済む。

3. **「押すと何を探すか」がボタンのそばに無い**
   - YouTube タブ（新しい指摘）: 要約は `src/components/youtube-channel-videos.tsx:187` に置かれていて、`src/components/url-search-panel.tsx:163` で作り、`:367` で一覧へ渡している。ボタン（`:285` の SearchCluster）からは約 700px 離れていて、スマホでは最初の画面の外になる。**要約の文を、ボタンの下（SearchCluster の中）へ移すだけ**で直る。新しい文は足さないので、「画面の文字を増やさない」【持】にも触れない。
   - X 検索タブ: 既知 Q-006（判断待ち）。YouTube タブで先にボタンの下に置いてみて、見た目が許せるなら X 検索タブにも同じ形で出す、という順番が安全。

## 4. 強み 3・弱み 3

強み
- **2 回目からは 1 タップ**: 保存した設定が自動で戻り、名前がタブに出て、「投稿を検索」は最初の画面に入っている（`sp-10-revisit.png`）。
- **下の固定ボタンの出し方が丁寧**: 上のボタンが見えている間、打っている間（タッチの端末だけ）、広告が見えている間は出さない（`src/components/floating-search.tsx:39-62`）。スマホでキーボードの上を塞がず、広告の押し間違いも避けている。
- **強弱の付け方**: シェアと引き継ぎのダイアログは、塗り → 枠 → 文字だけ、の順で役割どおりに強弱が付いている。320px でも横にはみ出さない。

弱み
- 押せる大きさ（上の 1）。
- 色の役割の混ざり（上の 2）。選んでいる物の見せ方が 2 通りある。
- 開発者情報が長い: トップの下で約 950px（スマホのページ 2,570px の約 37%）を取る。URL がそのまま文字で並び、`.../c` と `hannel/...` のように途中で割れる（`sp-03-added-full.png`、`src/components/developer-info.tsx`）。直し方の案: 名前そのものをリンクにして URL は出さない。関連サービスは閉じた状態の `<details>` にする。ただ、この一覧は共通の正本から書き写す形（コミット 39bd5c3）なので、書き方を変えるならほかのサービスとも揃える必要がある。

## 5. 必ず変えること

1. スマホの設定タブ・チップの ×・候補チップを、44px 前後で押せるようにする。× で消したら「元に戻す」を出す（Q-004）。
2. 選んでいる切り替えを濃い塗りにしない（`segmented.tsx:10`）。濃い塗りは「してほしいこと」だけにする。主色の見直し（Q-002）と一緒に、1 コミットで戻せる形にする。
3. YouTube タブの要約を、ボタンの下へ移す（`url-search-panel.tsx:285` の SearchCluster の中）。
4. 「ログイン不要」の言い方を直す（Q-016）。【持】の「画面の文字を増やさない」は、言い換えなので変えずに済む。

【持を変える】の提案は無い。

## 6. より良くするアイデア（芯を残すもの）

1. **PC で Ctrl+Enter（Mac は ⌘+Enter）で検索を開く**: 名前欄で打っている言葉を確定させてから開く。画面に説明は足さず、使い方のページに 1 行書くだけ（`chip-input.tsx:88` の onKeyDown）。
2. **ホーム画面からその設定で直接開く**（既知 Q-014）: スマホの毎日の手数が「アプリを開く → 押す」から「アイコンを押す」になる。親指が届かない問題（Q-013）も避けられる。
3. **選んでいる物の見せ方を 1 つにまとめる**: 設定タブと同じ「白い札」に揃える。部品は `segmented.tsx` の 1 か所なので、全部の切り替えが一度に揃う。

## 7. 一番安く早く確かめる方法

- **誰に**: 本人と、X を毎日使っている知人 2 人（1 人は iPhone）。
- **何分**: 1 人 5 分。
- **何を頼むか**: スマホで、空の状態から「自分の名前で、最新の投稿を X で見る」まで。そのあと「設定2 に推しの名前を入れて検索」「名前を 1 つ消す」。
- **何を見るか**: タップの回数、押し間違い（× を押してしまう・隣のタブを押してしまう）、最初にどこを押そうとしたか（最初の画面で「最新順」を押しに行かないか）、X のログイン画面で止まらないか。
- **やめる目安**: 3 人とも押し間違いが 0 回で、30 秒以内に X が開けたら、Q-004 と上の 2 の優先を下げて、Q-001・Q-016 を先に直す。

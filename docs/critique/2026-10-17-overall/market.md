# 市場調査: エゴサ支援ツール(ぬ)（2026-10-17）

調べた日: 2026-10-17。ウェブ検索と、公開ページの読み取りだけ。数字は出典 URL 付き。推定は「推定」、確認できなかったものは「未確認」と書く。

## 0. 先に結論（3 行）

1. 「X の検索コマンドを組み立てて開く」だけのツールは、英語圏では無料の同種が複数あり、日本語圏でも解説記事が多い。**これだけでは混んでいる**。違いになりうるのは「名前の表記ゆれ・3 つの設定の保存・除外ワード・YouTube 動画 URL を貼った投稿の検索」と、「配信者向けに寄せた日本語の作り」。
2. **「ログイン不要」は、このツールの側の話でしかない**。X の検索自体は、ログインしていないと開けない（2026-10-17 にこちらで確認、下記 3-1）。ログインなしで X の投稿を見られる近い手段は Yahoo!リアルタイム検索だけ。ここを画面で誤解させない書き方が要る。
3. X の検索は 2025 年 7 月・2026 年 3 月に仕様変更・不具合があり、名前検索の効き方が変わった（ユーザー名だけに一致する投稿は出ない、完全一致が不安定になった時期がある）。ツールの価値は「X の仕様に追従して正しいコマンドを作ること」に寄る。仕様追従を怠ると価値が消える。

## 2. 需要の目安（推定。数値は出せず）

- 「エゴサ」「X 検索 コマンド」の月間検索数は、今回の検索では**数値を確認できなかった**（Google Keyword Planner・Ahrefs・Semrush のような有料または広告アカウント必須の道具が要る。Google Trends の取得も 429 で失敗）。

  - 企業ブログが「検索コマンド一覧」を毎年更新して取りに行っている（上記 1-B）。更新が続くのは流入が見込めるから、と読める【推測】。

- **本人に確かめてほしいこと**: 自分の Search Console（クリック・表示回数・検索語）が、これまでの唯一の実数。審査中の AdSense の前に、どの語で流入しているかを見るのが一番安い。

## 3. X の検索仕様の最近の変化（このツールの土台）

### 3-1. ログイン
- **こちらで確認（2026-10-17）**: ログインしていないブラウザで `x.com/search?q=エゴサ&f=live` を開くと、ログイン画面（電話番号・Google・Apple・メールで続ける）に移される。つまり **X の検索はログイン必須**。
- 経緯: 2023 年から、ログインなしでの閲覧が制限された（出典: https://www.sungrove.co.jp/x-just-look/ 。同記事は 2025 年 7 月のもの。企業サイトで根拠が弱いので、確認できる範囲として上のこちらの確認を優先）。
- 影響: このツールの「ログイン不要・無料」は、**ツールの側にログインが無い**という意味。利用者は X のログインが要る。X のアカウントを持たない人（家族・ファンの一部）には使えない。画面の言い方を誤解させない書き方にするか、Yahoo!リアルタイム検索への案内が要る【推測: 実際の画面の文言は未確認。トップページを読み取りで取得したら「ログイン不要・無料」と明記されていた】。

### 3-2. 検索のしくみの変化
- 2025-07-01 の記事: **ユーザー名が検索対象から外れた**。検索語がユーザー名にだけ含まれる投稿は、検索結果に出ない。人を探すには［ユーザー］タブを使う。以前使えた「OR @i」でユーザー名を除外する手は、2023 年 5 月ごろから使えなくなっていた（https://roboin.io/article/2025/07/01/x-removes-usernames-from-search-index-two-years-after-blocking-exclusion-workarounds）。
  → 名前検索のノイズは減ったが、「名前がアカウント名にだけある投稿」は拾えない。**表記ゆれ候補の価値はむしろ上がった**（本文に書かれた言い方を網羅する必要があるため）。【推測】
- 2026-03-01 の記事: 2026 年 2 月 28 日ごろから、「最新」タブに無関係な海外投稿・スパムが出る、完全一致（ダブルクォート）が不安定、アカウント名が検索対象に含まれる、などの報告。筆者は X のサーバー側の問題と推測し、X の製品責任者が検索を新しいシステムへ移行中と投稿していたと書く。公式の原因確定ではない（https://roboin.io/article/2026/03/01/x-search-malfunction-exact-match-queries-failing-causes-and-fixes-explained）。
  → **現在（2026-10）も同じ状態かは未確認**。ツールが出す `"完全一致"` や `-除外語` の効きを、定期的に実機で見直さないと、画面の説明が嘘になる。
- 位置情報の演算子 `near:` `within:` は 2025〜2026 年時点でほとんど効かない（koukoku.jp の 2026 年版の記述。https://www.koukoku.jp/service/suketto/marketer/sns/%e3%80%902026%e5%b9%b4%e6%9c%80%e6%96%b0%e3%80%91x-%e6%a4%9c%e7%b4%a2%e3%82%b3%e3%83%9e%e3%83%b3%e3%83%89%e3%81%a8%e3%81%af%ef%bc%9fx%e6%a4%9c%e7%b4%a2%e3%82%b3%e3%83%9e%e3%83%b3%e3%83%89%e4%b8%80/ ）。このツールは使っていないはずだが、一覧ページに載せるなら注記が要る。
- 検索は人によって結果が変わる（おすすめ順・「最新」の混ざり方）ので、演算子が効いていないように見えることがある（https://multilogin.com/blog/twitter-x-search/ 。商用ブログなので参考程度）。
- 2026-03-27 前後: X Pro が Premium+ 限定に（上記 1-D）。

### 3-3. 仕様変更に弱い、という意味
- 静的サイト＋X API なし、の方針は、API の有料化・制限で消えたサービス群（上記 1-E）を避けている。これは強み。
- 一方、**x.com/search の URL と演算子の仕様に全面的に依存している**。URL 形式（`q=` `f=live` など）が変われば全部壊れる。壊れ方は静か（エラーではなく検索結果が変になる）。【推測】

## 5. 配信者・VTuber 界隈でのエゴサの習慣（今回の検索で分かった範囲）

- **確認できたこと**:
  - エゴサが配信の企画・ネタになる文化がある（夏色まつりさんの回: https://www.appbank.net/2025/11/06/youtubernews/2859402.php）。
  - ファンアートや感想はハッシュタグで集める習慣が強い。例: 夏色まつりさんの「#祭絵」。配信者が指定タグのファンアートを紹介する文化がある。AI 生成イラストをタグに載せられる問題も起きている（https://www.itmedia.co.jp/news/article/2210/11/1221011138/）。
  - エゴサは「全部見る／全く見ない」の二択より、見る時間・頻度を決める、見た後の対処（削除依頼、一人で抱えない）を決めておく、という説明が多い（https://monolith.law/reputation/function-method-ego-search 、配信者向けメンタル記事 https://bloomeria.jp/blog/streamer-mental-health-guide-2026 。**同記事内の「約 80% が数字のプレッシャー」のような割合は出典が示されておらず、使わない**）。
  - 日本語の解説では、エゴサ手順として「最新タブ＋since: で日付を絞る」「朝・昼・夕など確認時刻を決める」を勧めるものがある（https://tatap.jp/knowledge/x-realtime-search/）。
- **確認できなかったこと**: 個人の配信者・VTuber が実際にどの検索語・頻度でエゴサしているかの調査データ。マシュマロなど他の感想窓口との使い分け。**「配信者のエゴサ習慣」の数字は出せない**。
- 示唆（【推測】）:
  - 配信者にとってエゴサは「楽しい」と「傷つく」が両方ある行為。**ツールの価値は『見る範囲を自分で決められること』（除外ワード、3 つの設定を使い分け、毎回同じ範囲を開く）**。過剰に煽らず、見たくない語を外せるのは、メンタル面の説明と合う。
  - 催眠音声・ASMR は、作品名・声のタグ・ファンの呼び名が多い界隈【未確認】。表記ゆれ候補の使い道は大きいかもしれない。ただし**成人向けや刺激の強い内容の投稿は、X の「センシティブな内容」の設定で検索結果に出ないことがある**【推測。実機で未確認】。`filter:media` や `f=live` の結果が少なく見える原因になりうるので、画面の説明に入れるかどうかは作り手の判断。

## 7. このツールへの含意（次の会議役が使う用）

1. **混んでいる所で戦わない**: 検索コマンド一覧の記事で上位を狙う、検索 URL を組み立てるだけの道具で勝負する、はどちらも弱い。差は「配信者向けに寄せた表記ゆれ・保存・除外・YouTube 動画 URL」。
2. **無料で自動通知は出来ない**ので、ここを約束しない。代わりに「毎日同じ数本を 1 タップで開く」を売りにする。SocialDog Professional（月 $49）や X Pro（月 6,080 円）と並べると、0 円の位置は空いている。
3. **「ログイン不要」の言葉は、X のアカウントが要らないと誤解させやすい**。確認済みの事実（2026-10-17 に、ログインなしで x.com/search がログイン画面に移る）に合わせて直すか、ログインなしで見たい人に Yahoo!リアルタイム検索を案内するかを、作り手が決める。
4. **仕様追従が最大の運用**: X が検索を新システムに移行中という報告（2026-03）があるため、完全一致・除外語・日付の動作を、数か月に一度は実機で確かめる手順を持つ。壊れても気づきにくい。
5. **収益の想定は小さい**（推定）: 個人の静的ツール、検索流入が主、競合は大手企業ブログ。AdSense は流入に比例するので、数字は Search Console を見るまで置かない。応援（任意）は、作者の配信のファンが使う道具である点が効く【推測】。

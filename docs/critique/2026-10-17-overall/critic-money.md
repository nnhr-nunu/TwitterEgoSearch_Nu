## 3. 強み 3

1. **運用費が構造的にゼロ**: 静的エクスポート＋GitHub Pages、X の API なし、YouTube は 1 ユニット系だけ（AGENTS.md「制約」）。収益が 0 でも止める理由が出ない。X API の有料化で消えたエゴササービス群（market.md 1-E）と違い、続けられる形。
2. **0 円の位置が空いている**: 「毎日同じ検索を数本開く」を無料で持つ手段は、X Pro の Premium+ 化（2026-03-26、market.md 1-D）で減った。3 つの保存枠・表記ゆれ・除外語・YouTube 動画 URL の検索は、無料の同種（OpenTweet は保存なし）に無い（market.md 1-A）。
3. **広告の置き方が規約面で安全**: 検索ボタンから離す（search-app.tsx:550 のコメント）、配信されない枠はラベルごと隠す（ads.md:10）、開発時は `data-adtest`（ad-slot.tsx:85）。誤クリック狙いの配置をしていないので、審査が通ったあとに止められる危険が小さい。

## 4. 弱み 3

1. **広告が「費用だけ」になっている**: 上の 0 の事実。ローダー約 220KB を全ページで読み、スマホの遅い回線でトップの表示まで約 3.6 秒（Q-055、docs/quality-review.md:54）。収益 0 で表示を遅くしているので、使ってもらう・検索の評価の両方に損。
2. **使い方の形が広告と合わない**: 一番大事な操作（上の「投稿を検索」）で利用者はすぐ X へ移る。広告は最下部、縦長は広い画面だけ。さらに Q-014（ブックマークから X へ直行）を入れると常連の表示は 0 になる。常連ほど広告を見ない作り。
3. **応援・メンバーシップの入口が無い**: 開発者情報（src/components/developer-info.tsx:41-54）は X・YouTube 2 本・バグ報告だけ。YouTube メンバーシップの URL（NunuDB/profile.md:24）も GitHub Sponsors（申請中、profile.md:22）も置いていない。「任意の応援」が方針なのに、応援したい人が押す所が無い。

## 5. 必ず変えること（上位から）

1. **広告ローダーを「スロット ID があるときだけ」読むようにする**（ads.ts:36 の既定のパブリッシャー ID をやめるか、layout.tsx:52 の条件を `client && slot` にする）。審査用のサイト確認が要るのはルートの oshilog.life 側で、子ドメインのエゴサで今読む得は無い【推測】。あわせて ads.md:4-5 の記述を実態に合わせる。Q-055 の保留を、この事実で一歩進める扱い。【持を変える】ではない（Q-055 は判断待ちで、決定ではない）。
2. **応援の入口をフッターに 1 行だけ置く**: 開発者情報の「バグ報告は…」の下に「応援: YouTube メンバーシップ」（GitHub Sponsors が通ったらそちらを先に）。トップの画面に文を足さない【持】（メモリ no-more-ui-text.md）の範囲内（フッター程度のリンク）。**Fantia・クリエイティアなど成人向けを含む導線はこのツールには置かない**（core.md ③未成年。X 利用者全般が来る一般向けの道具なので）。
3. **お金の本線を「推しログへの送客」と決めて、文書ページで繋ぐ**: 推しのパブサをする人は推しログ（Stripe・YouTube メンバー判定を持つ本命、NunuDB/products.md:8・tech.md:24）の客層そのもの。関連サービス一覧（フッター）はすでにあるので、足すのは `/guide/` の末尾など文書ページだけ（例: 集めた推しの反応を推しログに残す使い方を 1 段落）。トップには足さない。
4. **広告を置くなら「読まれるページ」に寄せる**: 長く読まれるのは検索コマンド一覧（/guide/search-operators/）だが、ここは縦長の左右だけで本文下の枠が無い（src/app/guide/search-operators/page.tsx:4・213 は AdRailLayout のみ）。スマホの読者には 1 枠も出ない。審査が通ったら、ツールのトップより先にここの本文末に 1 枠。
5. **数字を 1 つ持つまで広告の作業をしない**: Search Console の 28 日のクリック数・表示回数（無料・コード不要）を本人が見る。これが無いまま広告やスロットに手を入れても、効いたか分からない。

## 6. より良くするアイデア（芯を残す、3 つまで）

1. **キャッチを「毎日のエゴサを、ワンタップで」に寄せる**: 0 円で空いている位置（毎日同じ数本を開く）がそのまま一行になる。合わせて「ログイン不要」を「登録不要」に（X のログインは要る事実、market.md 3-1。core.md ①誠実）。画面の文字数は増えない（置き換えだけ）。
2. **シェアの文例を「推し・配信者の応援」に寄せる**: シェアにはツールのハッシュタグ `#エゴサ支援ツールぬ` が付く（src/lib/share-post.ts:12）。「推しの感想を集めた」形の文例は、受け取った人＝推し活の人を連れてくる。お金への効き方は推しログ経由で間接【推測】。
3. **Q-014（X へ直行のブックマーク）は広告のために止めない**: 常連の広告表示は 0 になるが、中央試算で失うのは月数十円【推測】。常連の満足を取るほうが、応援・推しログへの送客で戻りが大きい。

# 製品の動き（短い正本）

検索結果は X で見る。このアプリは X の検索 URL（`x.com/search`）とポスト作成 URL（intent）を組み立てるだけ。

- 設定1〜3: 名前・愛称・ハッシュタグ（OR。2 つ以上なら「すべてのキーワードを同時に含む投稿だけ（AND検索）」で AND）・このアカウントの投稿だけ（`from:`）・この言葉も含む投稿だけ・除外するアカウント（`-from:`）／キーワード・期間（すべて／日付の前後／開始日〜終了日のどれか 1 つ）・画像・動画つきの投稿だけ。最新順（`f=live`）か話題のポスト順で開く。
  - 名前を入れると、ひらがな・カタカナ・半角カナ・空白なしの書き方を「表記ゆれ候補」として出す（押すまで検索に入れない。隠した候補はこの端末にだけ覚える）。
  - 除外するの「ネガティブワード」（初期はオフ）は、手で選んだ短い辞書（`src/lib/negative-words.ts`）の言葉を `-"言葉"` で足す。X の検索は約 500 文字までなので大きな辞書やライブラリは使わない。名前・絞り込みの言葉に入っている言葉は除外しない。
  - 上の検索ボタンが画面外のときだけ、画面の下に検索ボタンを出す（広告が見えているとき・スマホで入力中は出さない）。
- YouTube タブ: チャンネル・動画の URL から、そのリンクを貼った投稿（`url:`）を探す。チャンネルは YouTube Data API v3 で動画一覧を読み、期間・種類・タイトルで絞って 20 本ずつに分けて開く。
- シェア: 条件を `share=1` 付きの URL にしてポストできる。受け取った側の保存済みの設定は上書きしない。
- 初期画面は空。入力はブラウザの `localStorage` にだけ残す（サーバーには送らない）。
- ぬぬはらは作者の個人サンプルであり、初期値ではない。
- X の検索 API・スクレイピング・ログイン・有料 API は使わない。静的エクスポートのみ。

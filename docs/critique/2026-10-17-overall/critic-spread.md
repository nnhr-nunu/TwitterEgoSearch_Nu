## 1. 総合点と観点の点

**総合 3 / 5** — 共有の仕組み（条件入りリンク＋消せないハッシュタグ＋着地の「自分のエゴサをはじめる」）は個人ツールとして出来がよいが、配信者に一番効く場面（配信・動画の感想）で共有できず、検索からはほぼ見つからない（実数ゼロ・名前が探しにくい）。広がる道が今は「本人の告知 1 本」だけ。

## 2. 場面で見る

### スクショ 1 枚で何が伝わるか
- カード画像（`src/app/og.png/route.tsx:9-13`）: 「エゴサ支援ツール(ぬ)／名前も愛称も、まとめてエゴサ。／"名前" OR "愛称" OR "#タグ"／ログイン不要・無料」。**何のツールかは伝わる**。ただし「OR」は一般の人には記号で、「自分に何が起きるか」（感想が全部見られる・悪口を見ずに済む）が無い。
- 共有リンクのカードもこの 1 枚だけ（静的エクスポートなので、リンクごとの画像は作れない）。配信者が「◯◯の配信の感想まとめ」を貼っても、カードはツールの宣伝になる。ツールの広がりには効くが、**投稿した配信者のファンにとっては「何のリンクか」が本文頼み**。
- 画像の左上に Twitter の鳥に似た印と「TWITTER (X)」（`og.png/route.tsx:24-34, 80-83`）。X の商標の扱いに触れうる【推測。X のブランド規定は未確認】。公式と誤解されると通報の種になる。

### 15 秒・音なしのクリップで何が伝わるか（場面の想像）
- 0〜3 秒: 欄に「ぬぬはら」と打つ → 3〜6 秒: 「ヌヌハラ・ﾇﾇﾊﾗ…」の候補が出て押す → 6〜9 秒:「ネガティブワード」を入れる → 9〜15 秒: X が開いて感想が並ぶ。
- **一番目を引くのは候補がぽんぽん出る所と、悪口が消えた結果**。ただし「消えた」は前後比較が無いと音なしでは伝わらない。今の画面の言葉「ネガティブワード」（`src/lib/i18n.ts:26`）は機能名で、見る人の得（傷つかずにエゴサ）にならない。
- 結果は X 側の画面なので、クリップの後半はツールの外。ツールの手柄に見えにくい（構造上の弱み）。

### 人に見せたくなる瞬間・共有の手間
- 「この検索結果をシェア」（`src/components/search-cluster.tsx:123-128`）→ ダイアログ（文例: 自由・感謝・報告・シンプル、`src/lib/share-post.ts:101-111`）→「X でポスト」。**2 タップ**。ハッシュタグ `#エゴサ支援ツールぬ` は消せない（`share-post.ts:12, 124-127`）ので、広がった足跡を X で数えられる。良い作り。
- 既定の文例が「自由（空欄）」（`src/components/share-dialog.tsx:94`）。空欄から書くのは手が止まる。配信者が一番使う「感謝」（「◯◯への感想・反応を、ワンタップでまとめて見られるリンクを作りました」）が既定のほうが投稿まで行く【推測】。
- 着地（共有リンクを開いた人）: 「「ぬぬはら・#ぬぬはら絵」の検索結果」「X で検索結果を見る」「この条件を保存」「自分のエゴサをはじめる」（`src/components/shared-banner.tsx:97-137`、開発サーバーで表示を確認）。**受け取った人がそのまま次の使い手になる流れがある**。ここは強み。
- ただし X の検索はログインが要る（market.md 3-1、2026-10-17 確認）。「ログイン不要・無料」（`src/lib/i18n.ts:6-7`、カード画像、`src/lib/site-metadata.ts:7-8`）を見て開いた X 未登録のファンはログイン画面で止まり、「嘘じゃん」と感じる。既知 Q-016 の確認待ちと同じ根。広がる側から見ると、**誤解は共有された先で起き、悪い口コミになる**ので優先度を上げたい。

### 配信で視聴者が参加・反応できる所
- エゴサは配信の企画になる（market.md 5、夏色まつりさんの例）。このツールは「配信画面に映して、名前と除外を入れて、押す」がそのまま企画の手順になる。**悪口を外すスイッチを配信で入れる瞬間**は、視聴者が「優しい」「それ欲しい」と反応しやすい【推測】。
- 視聴者側の参加: 配信者が「感想は #◯◯ で」と言い、終わりに共有リンクを貼れば、ファンはリンクから他のファンの感想を読める（ファン同士がつながる）。今の仕組みで出来るが、**その使い方がどこにも書かれていない**（使い方 `src/app/guide/page.tsx:85`「イベントや配信の感想をまとめて読みたい」はあるが、配信者が「貼る」側の手順ではない）。
- **YouTube タブには共有が無い**（`ShareDialog` を使うのは `search-app.tsx` の X 検索タブだけ、`url-search-panel.tsx` に onShare なし）。配信者にとって一番自然な「この配信のアーカイブを貼った感想ポスト、ここで全部見られます」が出来ない。

### 検索で見つかるか
- 名前: 「エゴサ支援ツール(ぬ)」。括弧と「ぬ」は口コミで言いにくく打ちにくい（ハッシュタグでは「ぬ」を括弧なしにしている、`share-post.ts:11-12` のコメントのとおり）。人が「エゴサ支援ツール」で探したとき、推しログの子ドメインで一般語の名前は埋もれやすい【推測】。米国のウェブ検索で「エゴサ支援ツール(ぬ) self-search.oshilog.life」を引いても本サイトは出なかった（2026-10-17、こちらの検索は米国向けなので弱い根拠。日本の Google での表示は未確認）。
- title「エゴサ支援ツール(ぬ) | X(Twitter)のエゴサ・推しのパブサをまとめて検索」（`src/app/layout.tsx:26`）は、検索語が後ろにある（既知 Q-060）。`keywords` メタ（`layout.tsx:31-41`）は Google が使わないので効果なし（害もない）。
- 狙える語の現実（market.md 1-B・4）: 「X 検索コマンド一覧」は企業ブログが毎年更新して埋めている。正面からは取れない。**空いているのは「配信 感想 探し方」「VTuber エゴサ やり方」「YouTube 動画 感想 X 検索」「ファンアート 探し方 X」のような、具体的な場面の語**【推測。検索数は未確認】。使い方ページの節（`guide/page.tsx:24-85`）がちょうどこの場面ごとに書かれているのに、1 ページにまとまっているので、どの語でも「使い方」の 1 ページとしか見えない。

## 3. 一番広がりそうな瞬間 1 つと、それを強くする具体案

**瞬間: 配信・動画の終わりに、配信者が「今日の感想、ここで全部見られます」とリンクを貼る。** ファンはリンクから他のファンの感想・ファンアートを読み、着地画面の「自分のエゴサをはじめる」で、自分の推しや自分の名前で使い始める。配信者 1 人の投稿が、その配信者のファン全員にツールを見せる。本人（ぬぬはら）の配信で毎回できるので、外の配信者を待たずに始められる。

強くする具体案（どれも静的・API なし・DB なしのまま、【持】を変えない）:
1. **YouTube タブの動画 1 本・まとめて検索に「この動画の感想をシェア」を付ける**。文例は「「(動画の題)」の感想ポストを、ワンタップで全部見られます」。共有 URL に動画 URL を載せ、着地では「この動画の感想を X で見る」。（`url-search-panel.tsx`、`share-post.ts` の文例に `video` 型を足す）
2. **既定の文例を「感謝」にする**（`share-dialog.tsx:94`）。空欄から書かせない。
3. **カード画像を「得」の言葉にする**: 「配信の感想・ファンアートを、ワンタップでまとめて」＋「悪口を外して見られる」。「OR」の記号と「ログイン不要」を外し、鳥の印をツール自身の印に替える（`og.png/route.tsx:10-13, 24-34`）。1 枚で全リンクに効くので、変える価値が一番高い。
4. 使い方に「配信の終わりに感想リンクを貼る」の手順を 1 節（画面ではなく文書ページ。【持】画面に文字を足さない、に沿う）。

## 4. 強み 3・弱み 3

強み
1. **共有が 2 タップで、足跡（消せないハッシュタグ）と次の使い手への導線（着地の「自分のエゴサをはじめる」）がある**（`share-post.ts:124-127`、`shared-banner.tsx:135-137`）。広がりを数えられる設計は個人ツールでは珍しい。
2. **身バレ・晒しに配慮した共有**: 除外したアカウント・語は既定で載せない（`share-post.ts:18-21`、`i18n.ts:191-192`）。配信者が安心して貼れる。core.md ①安全に合う。
3. **配信者に刺さる差別化の材料が揃っている**: 表記ゆれ候補・悪口の除外・YouTube の動画 URL を貼った投稿の検索は、近い無料ツールに見当たらない（market.md 1-A・4）。

弱み
1. **一番配信者向けの YouTube タブに共有が無い**（上記）。差別化の機能が広がる仕組みにつながっていない。
2. **見つける入口が名前・告知・検索のどれも弱い**: 名前に「(ぬ)」、title の頭がサービス名、場面ごとの語を受けるページが無い、Search Console を見ていない。
3. **「ログイン不要」が共有された先で誤解になる**（既知 Q-016 と同根）。X 未登録のファンがログイン画面で止まり、カード・説明文の約束と食い違う。

## 5. 必ず変えること

1. **「ログイン不要」の言い方を直す**（キャッチコピー `i18n.ts:6-7`、カード `og.png/route.tsx:13`、説明 `site-metadata.ts:7-8`）。例「このツールは登録なし・無料（検索は X のアカウントで見ます）」を説明文に、カードからは外す。既知 Q-016 の確認を待たず、2026-10-17 の確認（market.md 3-1）で十分。
2. **YouTube タブに共有を付ける**（上記 3-1）。広がる場面と差別化を一本につなぐ。
3. **カード画像の言葉と印を替える**（上記 3-3）。共有リンクのすべてがこの 1 枚を見せる。鳥の印は X の商標規定を確かめるまで外す【推測の危険】。
4. **Search Console を開いて、実際の検索語と表示回数を見る**（本人のアカウントが要る。作業は 10 分）。数字無しで SEO の文面を変えない。
5. （判断材料として）アクセス解析が無いため共有リンクの効果が測れない。入れるなら Cookie を使わない無料のもの（Cloudflare Web Analytics など）でプライバシーポリシーに 1 行【AI案。入れるかは本人が決める。「DB・有料 API を足さない」【持】には触れないが、外部への送信が増える】。入れないなら、X で `#エゴサ支援ツールぬ` を検索して数えるのを効果の物差しにする。

## 6. より良くするアイデア（芯を残すもの）

1. **場面ごとの小さな文書ページ**: 使い方の 5 節（`guide/page.tsx:24-85`）を、それぞれ独立したページ（例 `/guide/stream-feedback/`「配信・動画の感想を X で全部見つける方法」、`/guide/fanart/`「推しのファンアートを X で探す方法」）にし、各ページの最後に「この条件で開く」リンク（条件入り URL）を置く。企業ブログの「コマンド一覧」と違い、**読んだその場で開ける**のが差。トップの画面には何も足さない（【持】に沿う）。
2. **「悪口を外してエゴサ」を売りの一言にする**: 画面の機能名「ネガティブワード」（`i18n.ts:26`）は変えなくてもよいが、カード・説明・告知では「見たくない言葉を外して見られる」を前に出す。配信者のメンタルの話題（market.md 5）と合い、煽らずに広げられる。
3. **本人の配信で毎回使う型を作る**: 配信の終わりに感想リンクを貼る（感謝の文例＋配信タグ）。本人の X で一番伸びるのは「作った物の告知」（overview.md 1）なので、初回は「配信の感想を全部見られるリンク、ツールで作れるようにしました」と機能告知として出し、2 回目以降は毎配信の定番にする。外の VTuber が真似しやすい見本になる。

## 7. 一番安く早く確かめる方法

- **誰に・何を**: 本人の次の配信 2〜3 回の終わりに、今の仕組みのまま（X 検索タブで配信タグ＋名前、「感謝」の文例）共有リンクを X に貼る。
- **何分**: 1 回 2 分。コードは変えない。
- **何を見るか**: その投稿の ♥・RT・リンクのクリック数（X の投稿のアナリティクス）と、1 週間後に X で `#エゴサ支援ツールぬ` を検索して、本人以外の投稿が何件あるか。並行して Search Console で直近 28 日の表示回数と検索語を 1 回見る。
- **やめる目安**: 3 回貼ってリンクのクリックが毎回 10 未満、本人以外のハッシュタグ投稿が 0 件なら、「配信者の共有で広がる」は弱いと判断し、YouTube タブの共有づくりは後に回して、場面ページ（アイデア 1）の検索流入に力を移す。クリックが伸び、他人の投稿が 1 件でも出れば、必ず変えること 2・3 を先にやる。
